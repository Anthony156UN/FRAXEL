# Recursos pendientes de subir

Para que la web se vea exactamente como el diseño aprobado, añade estos archivos **del ZIP FRAXEL_proyecto_completo.zip** a las rutas exactas:

- `img/anthony-hero.webp`
- `img/anthony-poster.webp`
- `img/anthony-poster-mobile.webp`
- `img/proximamente.webp`
- `videos/anthony-original.mp4`
- `videos/anthony-mobile.mp4`

Al faltar esos archivos, las imágenes y el video no se verán bien. No se han sustituido por versiones inventadas.

Puedes subir las carpetas completas desde GitHub web con **Add file → Upload files**, o desde Antigravity con Git.
